# 🎗️ Breast Cancer Prediction

## Machine Learning Research Prototype

A machine-learning based web application that demonstrates breast cancer classification using the Breast Cancer Wisconsin Diagnostic dataset and Logistic Regression.

## 🚀 Features

- Breast cancer classification
- Logistic Regression model
- Feature scaling using StandardScaler
- Model performance dashboard
- Accuracy, Precision, Recall and F1 Score
- ROC-AUC score
- ROC Curve
- Confusion Matrix Heatmap
- Model Explainability
- Prediction probability visualization
- Demo patient data
- Downloadable prediction report
- Streamlit web interface

## 🛠️ Technologies Used

- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Joblib
- Streamlit

## 📊 Dataset

Breast Cancer Wisconsin Diagnostic Dataset available through scikit-learn.

The dataset contains:

- 569 samples
- 30 numerical features
- Malignant and Benign classes

## 🤖 Machine Learning Model

The project uses:

**Logistic Regression**

Feature scaling is performed using:

**StandardScaler**
